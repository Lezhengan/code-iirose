# 古风小生替换器 (iiRose 插件)

> 小生这厢有礼了。不知姑娘/公子可愿一试此插件？

一个 iiRose 聊天室的自动文言转换插件。可将您的日常口语自动转换为**古风小生**风格的文言雅语，同时具备脏话过滤、繁简兼容、悬浮窗控制等功能。

---

## 功能特色

### 古风小生六艺

| 类别 | 示例 |
|------|------|
| **寒暄问候** | `你好` → 小生这厢有礼了，不知姑娘/公子今日可安好 |
| **绿茶阴阳怪气** | `心疼你` → 小生笨嘴拙舌，不会哄人，只能默默陪着姑娘了 |
| **道歉认怂** | `我错了` → 小生知错了，这就去面壁思过 |
| **告辞拒绝** | `拜拜` → 青山不改，绿水长流，小生这便退下了 |
| **深情表白** | `喜欢你` → 世人皆谓小生清冷，却不知小生的一腔温柔，皆给了姑娘 |
| **发疯沙雕** | `v我50` → 小生虽两袖清风，但若姑娘肯V小生50，小生愿为姑娘做牛做马 |

### 脏话自动过滤

覆盖 100+ 脏话、网络梗、拼音/英文变体（如 TMD、SB、草泥马、逆天、破防等），自动替换为文雅古语。

### 繁简兼容

内置 250+ 繁体字映射表，繁体输入自动转简后处理。

### 悬浮球控制

- 右侧悬浮胶囊，悬停展开，点击弹出设置面板
- 可独立开关 **敬语替换** / **礼貌句尾**
- 自定义敬称后缀（如先生、女士、君）

---

## 安装方法

1. 打开 iiRose 聊天室
2. 按 F12 打开开发者工具 → Console（控制台）
3. 将 [`iirose-keigo.js`](./iirose-keigo.js) 的全部内容粘贴到控制台，回车执行
4. 若提示跨域限制，请使用 iiRose 官方插件加载方式

### 自动加载（推荐）

将 `iirose-keigo.js` 的内容通过 iiRose 插件系统加载，刷新页面后自动生效。

## 工作原理

1. **拦截 WebSocket 发送** — Hook `socket.send` 方法，在消息发出前拦截
2. **分词替换** — 按标点符号分割短句，逐句应用正则替换规则
3. **层层递进** — 先古风小生六类 → 脏话过滤 → 动词书面化 → 疑问词雅化 → 句尾语气助词处理 → 礼貌句尾追加
4. **重复替换防护** — AABB/ABAB 叠词和四字成语预保护，长规则优先于短规则
